# WebP Image Resizer

A simple Python script to resize all `.webp` images in the current directory to 3 different widths: **400px**, **800px**, and **1200px**. Resized images are saved in a subdirectory called `resized_images`.

---

## 📦 Requirements

- Python 3
- [Pillow](https://python-pillow.org/) library

### Install Pillow on Arch Linux:
```bash
sudo pacman -S python-pillow
